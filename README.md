# TODO LIST

## アプリの概要

日々のタスクを登録・整理できる、Java製のTODO管理Webアプリです。

タスクに期限・カテゴリ・重要度・繰り返し設定を付けられます。タスクの状態や期限などで絞り込み、優先度や期限順に並べ替えることで、取り組むタスクを見つけやすくしました。タスクの追加や変更、完了、削除の履歴も確認できます。

## 主な機能

- タスクの追加、編集、完了・未完了の切り替え、削除
- 期限の設定と期限切れタスクの表示
- カテゴリ（買い物、家事、手続き、仕事、勉強、趣味、予定、その他）の設定
- 重要度（★1〜★3）の設定
- 毎日・毎週・毎月の繰り返しタスク
- 状態、期限、カテゴリ、重要度による絞り込み
- 追加順、タイトル順、期限順、カテゴリ順、重要度順での並べ替え
- 完了タスクの一括削除
- タスクの操作履歴の確認（最新50件）
- 完了数と全体に対する進捗率の表示
- スマートフォンの画面幅に合わせたレイアウト

## 使用技術

- Java
- Java標準の `HttpServer`（Webサーバー）
- SQLite
- SQLite JDBC
- HTML / CSS

## 起動方法

### 必要なもの

- Java 17以降
- リポジトリに含まれる `lib/sqlite-jdbc.jar`

### Windows（PowerShell）

リポジトリのルートディレクトリで、次のコマンドを実行します。

```powershell
javac -encoding UTF-8 -cp "lib/sqlite-jdbc.jar" App.java
java -cp ".;lib/sqlite-jdbc.jar" App
[http://localhost:8081](http://localhost:8081)

サーバーを終了するには、起動したターミナルで `Ctrl + C` を押してください。
```

## 確認方法

1. アプリを起動して、ブラウザでトップページを開きます。
2. タスク名、カテゴリ、重要度、期限、繰り返し設定を入力してタスクを追加します。
3. 一覧からタスク名や期限などを編集し、完了状態を切り替えます。
4. 一覧の見出しにある選択欄で、状態・期限・カテゴリ・重要度を絞り込みます。
5. 並べ替えを変更し、期限順や重要度順などで一覧を確認します。
6. 「操作履歴」から、タスクへの操作履歴を確認します。

## 工夫した点

### 必要なタスクを見つけやすい一覧

状態・期限・カテゴリ・重要度の条件を組み合わせて絞り込めます。並べ替え条件を変えても、選択中の絞り込み条件を引き継ぐようにしました。

### 期限を意識しやすい表示

期限を過ぎた未完了タスクを色で区別し、期限切れタスクだけを表示する絞り込みも用意しました。期限のないタスクも個別に確認できます。

### 繰り返しタスクの二重生成を防止

繰り返し設定のあるタスクを完了すると、次回分のタスクを生成します。生成済みかどうかをデータベースに記録し、同じタスクから次回分が重複して作られないようにしています。

### 変更内容を追える操作履歴

タスクの追加、編集、完了状態の変更、削除などを履歴として記録します。関連するデータ更新と履歴記録は、データベースのトランザクション内で処理しています。

### 入力値と表示内容への配慮

カテゴリや重要度、期限の値を処理時に確認し、HTMLに表示するユーザー入力はエスケープしています。また、日本語を扱えるように画面の文字コードとコンパイル時の文字コードをUTF-8にしています。

## データの保存

タスクと操作履歴は、アプリを実行するディレクトリにある `todos.db` に保存されます。
データベースや必要なテーブルは、アプリ起動時に作成・確認されます。
